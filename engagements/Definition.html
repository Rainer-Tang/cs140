ASCII and Unicode

ASCII is the system that use numbers to represent numbers, letters, and symbols and there are 128 characters. Unicode is the universal standard that contain all of the world languages and symbols

What is UTF-8

UTF-8 is a character encoding standard that converts human languages into binary data.

URL

URL stands for Unifrom Resource Locator which is the web address to find the specific page

Domain Name

Domain Name is the address that people can read and type to enter the page

HTTP

HTTP stands for Hypertext Transfer Protocol, which is the rule that computers use to send and receive messages on the internet

HTTPS

HTTPS is the more secure version of HTTP which will encrypts data during transit

IP Address

IP Address is a numberical label for each device

DNS

DNS stands for Domain Name System which can translate domain name to IP address

W3C

W3C is a international organization that create rules and standard for world wide web

XML, XHTML, HTML, HTML5

HTML(HyperText Markup Language) is the code used to build a web page, and XHTML(Extensible HyperText Markup Language) is the old version of HTML with stricted rules, any mistake could cause error on the page.

XML(Extensible Markup Language) is text file format used to store, organize, and transfer data by using custom tags.

HTML5 is the newer version of HTML with more features like build-in video and audio
