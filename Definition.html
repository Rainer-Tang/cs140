Internet

Internet is a large global network for computers to connect

Web

Web is the collection of different sources that runs on internet

How are the Internet and Web different?

Internet is like the highway, and the Web is the car running on it

ASCII and Unicode

ASCII is the system that uses numbers to represent numbers, letters and symbols, and there are 128 characters. Unicode is the universal standard that contains all of the world's languages and symbols

What is UTF-8

UTF-8 is a character encoding standard that converts human languages into binary data.

URL

URL stands for Uniform Resource Locator, which is the web address used to find a specific page

Domain Name

Domain Name is the address that people can read and type to enter the page

HTTP

HTTP stands for Hypertext Transfer Protocol, which is the rule that computers use to send and receive messages on the internet

HTTPS

HTTPS is the more secure version of HTTP, which encrypts data during transit

IP Address

IP Address is a numerical label for each device

DNS

DNS stands for Domain Name System, which can translate a domain name to an IP address

W3C

W3C is an international organization that creates rules and standards for the World Wide Web

XML, XHTML, HTML, HTML5

HTML(HyperText Markup Language) is the code used to build a web page, and XHTML(Extensible HyperText Markup Language) is the old version of HTML with stricter rules; any mistake could cause an error on the page

XML(Extensible Markup Language) is a text file format used to store, organize, and transfer data by using custom tags.

HTML5 is the newer version of HTML with more features like built-in video and audio
